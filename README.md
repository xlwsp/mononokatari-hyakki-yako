# モノノカタリ -百鬼夜行-

ブラウザで遊べる、ずっと続くオンラインのモンスター育成アクション（Phaser 3）。
URLを開けばいつでも途中参加。最大50人（少ないときはBotが参加）が同じ広いマップで遊びます。
PC（キーボード）とスマホ（縦画面・ドラッグ操作）の両方に対応。

## 起動

| やりたいこと | コマンド |
|---|---|
| 自分のPC・同じWi-Fiで遊ぶ | `python3 server.py` → http://localhost:8765 |
| **インターネットに公開**（URLを知っている人なら誰でも） | `bash start_online.sh` |

### ずっと同じURLで遊んでもらう（GitHub Pages）

遊ぶ人に送るURL: **https://xlwsp.github.io/mononokatari-hyakki-yako/**

- ゲームの画面は GitHub Pages から配信。ゲームの計算はこのMacで行う
- `bash start_online.sh` を起動すると、その時のサーバーのURLが GitHub（`server` ブランチの `server.json`）に自動で書き込まれ、
  ページは開いたときにそこを見て自動でつなぐ。止めると「サーバーが止まっているかも」と表示される
- ゲームのファイルを変更したら `bash publish_github.sh` で GitHub に反映（1〜2分で公開ページに反映）

- ゲームの計算はサーバー（このMac）が macOS 標準の JavaScriptCore（jsc）で行います。
  だれかが抜けたりスマホを閉じたりしても、世界は止まりません。追加インストールは不要です。
- **ずっと同じURLで公開したいとき**（おすすめ）：ngrok の無料アカウントを作り、`tools/online.conf` に
  Authtoken と無料ドメイン（例: `xxxx.ngrok-free.app`）を書いてから `bash start_online.sh`。初回だけ ngrok を自動でダウンロードします。
  - ngrok の無料プランでは、初めて開いた人に一度だけ確認画面（Visit Site）が出ます
- 設定がないときは Cloudflare の無料トンネル（アカウント不要）を使います。起動するたびにURLが変わります。
- 配信されるのはゲームのファイルだけです（`.py` `.sh` `tools/` は配信しない。`tools/online.conf` の秘密の情報も外に出ません）。

## 遊び方

- ランキングは人のプレイヤーだけ（Botは出ない）。Botは人より少し弱め
- **オートセーブ**：遊んでいる間ずっと自動でセーブ（2秒ごと・抜けたとき）。タイトルの「続きから」で前回の続き（レベル・強化・スコア）から再開。
  「初めから」は選んだモンスターでLv1から（セーブは消える）。やられたらセーブも消える
  - セーブはサーバー（このMacの `tools/saves.json`、配信されない）に、端末ごとの合言葉で保存。サーバーを再起動しても残る
- **ハイスコアランキング**：タイトルの「🏆 ランキング」で全期間の上位30人（人のプレイヤーだけ・1人1つの自己ベスト）。自分の順位も表示。記録は `tools/highscores.json`
- タイトルで名前とモンスターを選んで「オンラインで遊ぶ」→ すぐに世界へ参加（名前が空なら入力のカットインが出る。空のままOKなら「ゆうしゃ」）
- **モンスター（妖怪）**：最初はゲコまる・マイマイ・スズネの3体。ほかはガチャで手に入る（下の「妖怪ガチャ」）
  - 500 コダマ / 1,200 コハク / 2,000 ランギョ / 3,000 ウロコ / 4,500 クロロ / 6,500 ネジまる / 9,000 ハクア / 12,000 コモリ / 16,000 トオシビ / 22,000 シノノメ
  - 順番はBot同士の対戦シミュレーションで測った強さ順
- 移動: WASD / 矢印キー / 画面をドラッグ。通常攻撃とスキルは自動
- 敵を倒して経験値 → レベルアップで強化カードを3枚から選ぶ（← → で選択、Enter で決定、1/2/3・タップでもOK）
  - モンスター固有の能力を伸ばすカード（例：「ベロ伸ばし 強化」「白狼の咆哮 連発」「威圧 覚醒」）
- **Lv30で進化**：姿が変わり、攻撃と体当たりが3倍・HP2.5倍（全回復）・スキルの間隔が4割短く・足が速く・自然回復・体も大きく（自然回復は進化で毎秒 最大HPの0.5%）
- 最初は敵より小さいコマ。強くなるほど大きくなり（上限なし。Lv20から先は少しずつ。カメラも引く）、Lv5/10/15/20/30/40でオーラが豪華に（金の後光・虹色…）
- レベルは自分の分だけ左上に表示（他の人のレベルは表示しない）
- 体当たりのダメージは「固定＋相手の最大HPの数%」（上限なし）。大きくなっても6〜8回ほどで決着
- 他のプレイヤーとぶつかると**体当たり**：お互いにダメージが入り、はじき合う。HPが0になった方がやられる。倒すと相手の経験値の85%＋ボーナスを獲得
- 当たり判定は見た目の大きさに比例
- 低レベル（Lv1〜9）は経験値ボーナス（Lv1で+60%、だんだん減ってLv10で0）。高レベルでも必要経験値はゆるやかに増える
- やられたらモンスターを選び直して再出撃（Lv1から）
- 出撃後10秒は体当たりされない
- レベルが上がると少しずつ速くなる（Lv30まで。カメラが引いても遅く感じないように）。格下ほど少し速い（最大+15%）。Botはずっと格下は狙わない
- 持っているカードは画面左下に「⚔️攻撃×3」のように表示。レベルアップのカードにも「いま ×N」
- 敵: 用意したイラストの妖怪だけ（images/ の lv1〜lv4・雑魚敵 → assets/ek_*.png）。笠おばけ・ちょうちんは群れで出て、まとめて倒せる。倒すと「ポンッ」と弾ける音（コンボで音が高くなる・大きい敵は「ドパンッ」、ボスは「ドドーンッ」）。たまに金色の笠おばけ（逃げ回るボーナス）
  ゴールドスライム（逃げ回る・倒すと経験値がたくさん）、ボス（100秒ごとにどこかに出現）、28秒ごとに群れが押し寄せる
- レーダー：まわり約3200の範囲＋右下に世界全体での現在地。赤＝敵モンスター（ボスは遠くても表示）、他プレイヤーはレベルで色分け（赤＝格上 / 黄＝同じくらい / 緑＝格下）。オンラインの人は水色のふちで大きめに表示（範囲外の矢印も水色）、範囲外は矢印
- モンスターは丸いコマで表示（`tools/prepare_assets.py` が顔の位置に合わせて切り抜き、すき間はキャラの色で埋める）

## 高レベルの遊び（Lv12〜）

- **強敵**：Lv12から、赤く光る大きな強敵が混ざる（HP5倍・攻撃2倍・経験値6倍）。レーダーでは紫
- **範囲攻撃**：ボスと大きな強敵は、赤い円で予告してから地面をたたきつける（円の外へ逃げればよける）
- **妖怪ガチャ**：妖怪はガチャで手に入る（最初はゲコまる・マイマイ・スズネの3体）。レア度 ★50%・★★30%・★★★15%・★★★★5%、10連は★★以上1体確定。
  同じ妖怪が出ると★が上がる（★2に1体・★3に2体・★4に4体・★5に8体）。★1つごとに攻撃+6%・スキル威力+15%・スキル待ち時間-5%・受けるダメージ-4%、★5で特性も覚醒＋スキル威力さらに+25%。★MAXでまた出たら30P返却。
  前の「累計EXPで解放」で手に入れていた妖怪は、そのまま引きつぐ。ガチャ画面のタブで「装備ガチャ」（アイテム）も引ける
- **妖怪の段階**：レベルが上がると新しい妖怪が順番に出てくる。
  第1段階（Lv1〜）笠おばけ・ちょうちん／ボス化け提灯（Lv5〜）、第2段階（Lv15〜）狐・狸／ボス大蛇（Lv30〜）、
  第3段階（Lv60〜）鬼・妖狸／ボス獅子（Lv90〜）、第4段階（Lv150〜）ボス白獅子神。数分ごとの「ボス出現」はその人の段階のいちばん強いボスが硬くなって出る
- **フィールドボス**：段階ボスは各プレイヤーのまわりに20〜30秒ごと（Lv200以上は2体ずつ）出る。おともの雑魚つき。世界に最大70体。倒すと経験値の玉がどさっと出る
- **高レベル向け調整**：Lv150から敵の攻撃の伸びがゆるやかに。Lv100以上は1回に受けるダメージが最大HPの6%（Lv200以上5%、ボス10%）まで
- **大妖（ビッグボス）**：世界の中央に大妖「オオマガツ」が1体だけ現れる（開始90秒後・倒されると3分後に再出現）。レベルは出るたびに Lv100〜1000（100刻み）からランダムで、高いほどHP・攻撃・ごほうびが大きい（Lv200でHP60万、Lv1000で約217万）。とてもゆっくりだが、大きな範囲攻撃・雑魚の呼び寄せ。みんなで削って倒すと、経験値の玉が世界の中央に何重もの輪の形で520個並ぶ（玉の量・とどめのスコアとガチャPもレベルに比例して増える。Lv200でスコア+5000・ガチャ50P）。レーダーではどこにいても紫で表示
- **百鬼夜行**：4分ごと。Lv20以上の人のもとへ強敵の大群と大妖怪（ボス）が45秒間押し寄せる。15秒前に予告。
  生き延びると大量の経験値・スコア・HP全回復
- **賞金首**：Lv15以上でいちばんスコアの高い人が賞金首（💰）。どこにいてもレーダーに映る。倒すと大量のスコアと経験値
- 高レベルほど敵の攻撃が痛くなる（低レベルの人に当たるときはその人のレベル相当に弱まる）
- 試合中のランキングはBotも含めた本当の順位。Botは1位と最下位だけ表示（🤖）
- BGM：和の音階の曲（百鬼夜行やボスが近いと激しくなる）。左上の「♪」ボタンで 大 / 小 / OFF

## 強化カード

- どのカードも「足し算」で積み上がる（何枚でも取れて、枚数に比例して強くなる）
- HPカード（タフネス）は30枚まで。レベルアップでのHPアップは無限

## ガチャと装備

- 5レベル上がるごとに **ガチャポイント**（Lv5で10P、Lv10で20P、Lv30で60P、Lv50で100P…高レベルほど多い）。進化すると100P。ロビーの「🎲 ガチャ」で 100P につき1回（10連は1000P）
- アイテム（全10種・それぞれ役割がちがう）。「対人」のものはほかのプレイヤーにも当たる（相手の最大HPの割合ダメージ。守られている人には当たらない）
  - 小剣：回る刃（近接・対人）／勾玉：回って回復＋被ダメ減（守り）／赤ファイア：爆発する火の玉（遠距離）／青ファイア：3方向・スロー（足止め）
  - 破魔弓：遠くのプレイヤーを優先して狙撃（対人）／雷太鼓：敵から敵へ連鎖する雷（群れ）／八咫鏡：被ダメ減＋反射（守り）
  - 天狗の羽団扇：突風で敵も人も吹き飛ばす／打ち出の小槌：経験値+・吸い寄せ+（稼ぎ）／手裏剣：全方向に投げる
  - レアリティが上がると数・威力・間隔・効果量が上がる。Botもたまに弱めの装備を持つ
  - 同じ装備がかぶると＋強化（2個目で+1、最大+5。1つにつき威力・効果+12%）
  - 妖怪と装備の「組み合わせ」（秘密。装備すると「組み合わせ効果アップ！」で分かる）：威力・効果+30%、間隔-15%（一覧は js/sim.js の COMBOS）
  - 賞金首を倒すとアンコモン以上の装備がドロップ
- 大妖は Lv1000 固定（HP3億。高レベルの人がみんなで削る）
- ヌシ：マップの4か所（北西・北東・南西・南東）に1体ずつ。鬼のヌシ／化け狸のヌシ（lv3強敵の絵を大きく）。レベルは出現時の「いちばん高いプレイヤーのレベル×1.3」、HPはその人が一人で40〜60秒かかるくらい。突進・たたきつけ・呼び寄せあり。倒されると2分で復活し、持ち場のまわりに経験値の玉が輪の形で並ぶ。頭の上に名前とHP、レーダーに大きな印
- 大妖・ヌシに重なると大ダメージ（体当たり）：最大HPの20〜45%（相手のレベルが上ほど痛い）。上限なし
- 大妖の突進：1.1秒の赤い帯で予告してから猛スピードで突っ込む（6〜8秒ごと、HP半分以下は4〜5秒ごと）。当たると防御を無視して最大HPの50〜85%（大妖とのレベル差しだい）＋はじき飛ばし＋「妖気の傷」（8秒間 自然回復なし・回復スキル半分。名前の横に💔）。突進の終わりに着地の衝撃（たたきつけ）。ダッシュで横によければ避けられる
- 高レベルでも敵の体当たりは油断できない：1回のダメージ上限は 大妖20%・ボス14%・強敵（紫）9%（ほかは5〜6%）
- 高レベル向け：Lv300から先は必要経験値の伸びがゆるやか。Lv300以上の人の近くに60〜90秒ごとに「妖気の渦」（45秒）が現れ、中にいると経験値×1.5〜2.5（高レベルほど大きい）＆敵がたくさんわく。レーダーに紫で表示
- ダッシュ：Shift／スペース（スマホは右のダッシュボタン）を押している間、1.7倍の速さ。スタミナ満タンで3秒、使い切ると満タンに戻るまで10秒使えない（途中でやめた分はすぐ使える）
- 対人戦：通常攻撃もプレイヤーに当たる（どの妖怪でも1秒あたり相手の最大HPの約6%。1回の発射で当たるのは1発）。体当たりは控えめ（最大HPの3%＋少し）
- 毎日のお題（3つ・0時に更新・クリアで自動でポイント）とログインボーナス（1日目100P、連続で+50P、7日目以降400P）
- 画面右に記録：プレイヤー同士のキル（Botがからむものは出ない）・大妖の討伐・ドロップ・お題クリア
- 全体チャット（server.py の CHAT_ON で切りかえ）
- レアリティ：コモン50% / アンコモン28% / レア15% / エピック6% / レジェンド1%。レアリティの色のオーラつき（レジェンドは虹色）
- 装備のダメージには、カードで上げた攻撃力・連射・スキル威力も乗る（強くなるほど装備も強く）
- ロビーの「🛡 装備」でモンスターごとに1つ装備。ゲーム中は体のまわりを回り、触れた敵にダメージ。
  1つでもまわり8方向に並ぶ。レアリティが高いほど威力が上
- ポイント・持ち物・装備はサーバー（`tools/profiles.json`、配信しない）に端末ごとに保存
- 戦績（ロビーの「戦績」）：妖怪ごとの最高Lv・最高スコア・最多キル・回数／最近60回のプレイ／スコアとキルの上位（名勝負）。1回のプレイ＝やられるまで
- 道具屋：使い捨ての道具をポイントで買い、3種類まで持っていける。1回のプレイで1つにつき1回（Z/X/C か右下のボタン）。使った分だけ減る
  - 回復薬（HP50%）／透明化ポーション（6秒、敵にも人にも狙われない）／ランダムワープ／石化の札（まわり3秒）／毒ポーション（まわりに毒）
- 進化スキル：進化すると2つ目のスキルを覚えて自動で発動（一覧は js/sim.js の EVO_SKILLS）
- コモリの甲羅バリアは、最近2秒くらいで最大HPの1割以上くらったときだけ張る
- Botもダッシュする（逃げるとき・追いつけそうなとき）
- エモート（💬 か E キー）：8種類は無料。ピンズ6種類はやりこみの着せ替えで買う
- ロックオン（🎯 か Q キー）：オンの間は、近く（620以内）の人・ボス・強敵をねらい続ける
- 通常攻撃の弾は、ボス・強敵・人に10倍のダメージ（ふつうのモンスターはそのまま）
- 強いBot：1位のレベルの50〜70%のBotが5〜10人くらいいるように出てくる
- 着せ替えは買う前に試着できる（1回押すとプレビュー、もう1回で購入）
- 妖怪ごとの称号（やりこみ → 称号 → 妖怪ごと）：その妖怪で遊んだときだけ数える（例：マイマイで回復した量10万 → 【タフネス】）
- やられた画面の「🗺 通った道」：通った道とキル・ボス・進化・やられた場所を地図で見られる
- 左下のスキル欄に、通常攻撃1発のダメージとスキル威力、進化スキルのチャージを表示

## 更新のしかた（メンテナンス）

`bash update.sh` を実行すると、遊んでいる人はロビーへ戻り「メンテナンス中」になり（遊べない）、
GitHub Pages に公開 → 反映を待つ → サーバー再起動 → メンテナンス終了。終わると遊んでいる人の画面は自動で最新版を読み込み直す。
セーブ・ポイント・装備はそのまま残る

## 素材

`images/` の元画像から、背景を抜いてやわらかくしたスプライトを `assets/` に生成しています（元画像は変更しません）。

```bash
python3 tools/prepare_assets.py             # 全部
python3 tools/prepare_assets.py creatures   # モンスターだけ
```

## 構成

| ファイル | 役割 |
|---|---|
| `server.py` | 配信 + WebSocket + ずっと続く世界の管理（最大50人） |
| `tools/sim_driver.js` | サーバー側でゲームを計算する（jsc で実行） |
| `start_online.sh` | インターネット公開（Cloudflareトンネル） |
| `js/sim.js` | ゲームロジック・マップ生成・バトル・スキル・Bot AI |
| `js/net.js` | サーバーとの通信 |
| `js/fx.js` | 派手な演出（紙吹雪・後光・フラッシュ・コンボ…） |
| `js/scenes/*.js` | タイトル・ゲーム・HUD・再出撃画面 |
