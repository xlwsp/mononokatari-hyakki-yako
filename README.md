# モノノカタリ -百鬼夜行-

ブラウザで遊べる、ずっと続くオンラインのモンスター育成アクション（Phaser 3）。
URLを開けばいつでも途中参加。最大50人（少ないときはBotが参加）が同じ広いマップで遊びます。
PC（キーボード）とスマホ（縦画面・ドラッグ操作）の両方に対応。

## 起動

| やりたいこと | コマンド |
|---|---|
| 自分のPC・同じWi-Fiで遊ぶ | `python3 server.py` → http://localhost:8000 |
| **インターネットに公開**（URLを知っている人なら誰でも） | `bash start_online.sh` |

### ずっと同じURLで遊んでもらう（GitHub Pages）

遊ぶ人に送るURL: **https://xlwsp.github.io/nakama-survivor/**

- ゲームの画面は GitHub Pages から配信。ゲームの計算はこのMacで行う
- `bash start_online.sh` を起動すると、その時のサーバーのURLが GitHub（`server` ブランチの `server.json`）に自動で書き込まれ、
  ページは開いたときにそこを見て自動でつなぐ。止めると「サーバーが止まっているかも」と表示される
- ゲームのファイルを変更したら `bash publish_github.sh` で GitHub に反映（1〜2分で公開ページに反映）

- ゲームの計算はサーバー（このMac）が macOS 標準の JavaScriptCore（jsc）で行います。
  だれかが抜けたりスマホを閉じたりしても、世界は止まりません。追加インストールは不要です。
- **ずっと同じURLで公開したいとき**（おすすめ）：ngrok の無料アカウントを作り、`tools/online.conf` に
  Authtoken と無料ドメイン（例: `xxxx.ngrok-free.app`）を書いてから `bash start_online.sh`。初回だけ ngrok を自動でダウンロードします。
  - ngrok の無料プランでは、初めて開いた人に一度だけ確認画面（Visit Site）が出ます
- 設定がないときは Cloudflare の無料トンネル（アカウント不要）を使います。起動するたびにURLが変わります。
- 配信されるのはゲームのファイルだけです（`.py` `.sh` `tools/` は配信しない。`tools/online.conf` の秘密の情報も外に出ません）。

## 遊び方

- ランキングは人のプレイヤーだけ（Botは出ない）。Botは人より少し弱め
- **オートセーブ**：遊んでいる間ずっと自動でセーブ（2秒ごと・抜けたとき）。タイトルの「続きから」で前回の続き（レベル・強化・スコア）から再開。
  「初めから」は選んだモンスターでLv1から（セーブは消える）。やられたらセーブも消える
  - セーブはサーバー（このMacの `tools/saves.json`、配信されない）に、端末ごとの合言葉で保存。サーバーを再起動しても残る
- **ハイスコアランキング**：タイトルの「🏆 ランキング」で全期間の上位30人（人のプレイヤーだけ・1人1つの自己ベスト）。自分の順位も表示。記録は `tools/highscores.json`
- タイトルで名前とモンスターを選んで「オンラインで遊ぶ」→ すぐに世界へ参加（名前が空なら入力のカットインが出る。空のままOKなら「ゆうしゃ」）
- **モンスター解放**：最初はゲコまる・マイマイ・スズネの3体。累計獲得EXP（この端末に保存）で順に解放。強いモンスターほど後半
  - 500 コダマ / 1,200 コハク / 2,000 ランギョ / 3,000 ウロコ / 4,500 クロロ / 6,500 ネジまる / 9,000 ハクア / 12,000 コモリ / 16,000 トオシビ / 22,000 シノノメ
  - 順番はBot同士の対戦シミュレーションで測った強さ順
- 移動: WASD / 矢印キー / 画面をドラッグ。通常攻撃とスキルは自動
- 敵を倒して経験値 → レベルアップで強化カードを3枚から選ぶ（← → で選択、Enter で決定、1/2/3・タップでもOK）
  - モンスター固有の能力を伸ばすカード（例：「ベロ伸ばし 強化」「白狼の咆哮 連発」「威圧 覚醒」）
- **Lv10で進化**：姿が変わり、攻撃と体当たりが2倍・HP1.5倍・スキル強化
- 最初は敵より小さいコマ。強くなるほど大きくなり（カメラも引く）、Lv5/10/15/20/30/40でオーラが豪華に（金の後光・虹色…）
- レベルは自分の分だけ左上に表示（他の人のレベルは表示しない）
- 他のプレイヤーとぶつかると**体当たり**：お互いにダメージが入り、はじき合う。HPが0になった方がやられる。倒すと相手の経験値の85%＋ボーナスを獲得
- 当たり判定は見た目の大きさに比例
- 低レベル（Lv1〜9）は経験値ボーナス（Lv1で+60%、だんだん減ってLv10で0）。高レベルでも必要経験値はゆるやかに増える
- やられたらモンスターを選び直して再出撃（Lv1から）
- 出撃後10秒は体当たりされない
- レベルが上がると少しずつ速くなる（Lv30まで。カメラが引いても遅く感じないように）。格下ほど少し速い（最大+15%）。Botはずっと格下は狙わない
- 敵: スライム・コウモリ・ウィスプ・キノコ・カブトムシ・ブルート・ゴーレム。
  ゴールドスライム（逃げ回る・倒すと経験値がたくさん）、ボス（100秒ごとにどこかに出現）、28秒ごとに群れが押し寄せる
- レーダー：まわり約3200の範囲＋右下に世界全体での現在地。赤＝敵モンスター（ボスは遠くても表示）、他プレイヤーはレベルで色分け（赤＝格上 / 黄＝同じくらい / 緑＝格下）、範囲外は矢印
- モンスターは丸いコマで表示（`tools/prepare_assets.py` が顔の位置に合わせて切り抜き、すき間はキャラの色で埋める）

## マップ「ふわもこの森」（10000×10000）

シードから自動生成（全員同じマップ）。木は外周の枠だけ。中央の広場から4本の小道。
北東=紅葉 / 南西=深緑 / 北西=花畑 / 南東=岩場。

## 素材

`images/` の元画像から、背景を抜いてやわらかくしたスプライトを `assets/` に生成しています（元画像は変更しません）。

```bash
python3 tools/prepare_assets.py             # 全部
python3 tools/prepare_assets.py creatures   # モンスターだけ
```

## 構成

| ファイル | 役割 |
|---|---|
| `server.py` | 配信 + WebSocket + ずっと続く世界の管理（最大50人） |
| `tools/sim_driver.js` | サーバー側でゲームを計算する（jsc で実行） |
| `start_online.sh` | インターネット公開（Cloudflareトンネル） |
| `js/sim.js` | ゲームロジック・マップ生成・バトル・スキル・Bot AI |
| `js/net.js` | サーバーとの通信 |
| `js/fx.js` | 派手な演出（紙吹雪・後光・フラッシュ・コンボ…） |
| `js/scenes/*.js` | タイトル・ゲーム・HUD・再出撃画面 |
